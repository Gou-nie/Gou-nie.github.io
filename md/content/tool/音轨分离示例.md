# 音轨分离示例 🎧

一段现场合成的示例旋律，不用导入音频、不下载模型：人声和伴奏都在浏览器里现算。

可以直接试听、切换人声/伴奏、看旋律卷帘，也能把这份旋律导出成 MIDI、五线谱（SVG）、简谱（SVG）或 MusicXML；五线谱和简谱会先弹窗预览，确认排版后再下载。
